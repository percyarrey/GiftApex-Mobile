=================================================================
BACKEND AI INSTRUCTIONS - Announcements with Carousel & Image Support
=================================================================

The GiftApex mobile app has been updated to support:
1. Image-only announcements (full-width carousel slides)
2. Announcement duration (auto-expiry in days)
3. Horizontal carousel display on the user home screen

Below are the backend changes required.

=================================================================
MONGODB/MONGOOSE SCHEMA
=================================================================

Update your Announcement model to include these additional fields:

```javascript
const AnnouncementSchema = new mongoose.Schema({
  title: { type: String, trim: true }, // optional now
  message: { type: String, trim: true }, // optional now
  type: { type: String, enum: ["text", "image"], default: "text" },
  imageUrl: { type: String, default: null }, // required if type === "image"
  priority: { type: String, enum: ["info", "success", "warning", "important"], default: "info" },
  duration: { type: Number, default: 7 }, // in days; 0 means never expires
  expiresAt: { type: Date, default: null }, // computed from duration on creation
  createdAt: { type: Date, default: Date.now }
});

// Pre-save hook to compute expiresAt based on duration
AnnouncementSchema.pre("save", function (next) {
  if (this.duration && this.duration > 0) {
    const expiry = new Date();
    expiry.setDate(expiry.getDate() + this.duration);
    this.expiresAt = expiry;
  } else {
    this.expiresAt = null; // never expires
  }
  next();
});
```

=================================================================
API ENDPOINTS
=================================================================

1. POST /api/admin/announcements
   Description: Create a new announcement
   Headers: { "Content-Type": "application/json", "x-user-email": "admin@email.com" }
   Body (text type):
   ```json
   {
     "type": "text",
     "title": "New Feature!",
     "message": "We've added a new feature...",
     "priority": "info",
     "duration": 7
   }
   ```
   Body (image type):
   ```json
   {
     "type": "image",
     "imageUrl": "https://example.com/promo-banner.jpg",
     "priority": "info",
     "duration": 3
   }
   ```
   Response: { success: true, announcement: { ... } }

2. GET /api/admin/announcements
   Description: Get all announcements (admin view, includes expired)
   Headers: { "x-user-email": "admin@email.com" }
   Response: [ { _id, title, message, imageUrl, type, priority, duration, expiresAt, createdAt }, ... ]

3. DELETE /api/admin/announcements/:id
   Description: Delete an announcement
   Headers: { "x-user-email": "admin@email.com" }
   Response: { success: true }

4. GET /api/mobile/announcements
   Description: Get active (non-expired) announcements for users
   Headers: { "x-user-email": "user@email.com" }
   Logic: Filter out announcements where expiresAt < now (if expiresAt exists)
         Sort by createdAt descending (newest first - for carousel display)
   Response: [ { _id, title, message, imageUrl, type, priority, createdAt }, ... ]

=================================================================
IMPORTANT NOTES
=================================================================

- "type": "text" => requires "title" and "message" fields
- "type": "image" => requires "imageUrl" field; title/message are not needed
- "duration": number in days (1, 3, 7, 14, 30, or 0 for never expires)
- The user-facing GET /api/mobile/announcements should ONLY return non-expired announcements
- The admin GET /api/admin/announcements can return ALL announcements (including expired)
